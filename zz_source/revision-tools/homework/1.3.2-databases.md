(Accept: each product on an order must become its own row / separate order-line table.)

**4 (b) [2]** It is a **partial dependency** — a non-key attribute depends on only part of a composite primary key (1). It is removed by converting to **Second Normal Form (2NF)** (1).

**5. [2]** Durability: once a transaction has been committed, its changes are permanent — they are written to non-volatile storage (e.g. via a transaction log) (1). So if the server loses power after the commit, the payment is not lost — the committed change survives the failure/restart (1).
