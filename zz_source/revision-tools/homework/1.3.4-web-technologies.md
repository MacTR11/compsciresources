**Part B (6 marks)**

**6. [2]** A switch connects devices *within* a LAN and forwards frames to the intended device using **MAC** addresses (1). A router connects *different* networks (e.g. a LAN to the internet) and forwards packets between them using **IP** addresses (1).

**7. [2]** Symmetric encryption uses the *same* secret key to encrypt and decrypt, so the key itself must be transferred to the other party — and if it is intercepted in transit, all security is lost (1). Asymmetric encryption uses a public/private key pair: the public key can be shared openly because only the never-shared private key can decrypt, so no secret ever needs to be exchanged (1).

**8. [2]** A primary key is an attribute that uniquely identifies each record in a table (1). A foreign key is an attribute in one table (e.g. `CustomerID` in `Order`) that holds/references the primary key of another table, linking each order to its customer (1).
